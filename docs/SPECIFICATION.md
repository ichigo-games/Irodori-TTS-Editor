# 彩エディター 仕様書

更新日: 2026-09-13  
対象: このリポジトリの実装（Post Processingのレビュー修正まで）

## 1. 名称・目的・範囲

正式な呼び名は **彩エディター**。既存の技術名は `Irodori-TTS-Editor`。フォルダ名、起動ファイル、API、`.irodori` 拡張子は変更しない。
Windowsローカル環境でIrodori-TTSを使用し、YouTubeナレーションを行単位で編集・生成・確認して、YMM4用WAV＋字幕txtとして出力する。
現在はFastAPIとブラウザによるWebアプリ。専用デスクトップウィンドウやインストーラーは未実装。Voice Design自体はこのエディターの機能ではない。

## 2. 構成・起動

| 項目 | 現在の仕様 |
|---|---|
| 作業フォルダ | `E:\Irodori-TTS-Editor` |
| TTS本体 | 既定 `E:\Irodori-TTS`。`IRODORI_HOME`で変更可能 |
| Python | TTS本体の `.venv\Scripts\python.exe` を利用 |
| 起動 | `start.bat` または `start.ps1` → `run.py` |
| 接続 | `http://127.0.0.1:8765/` |
| データルート | 通常は作業フォルダ。`EDITOR_DATA`で分離可能 |
| UI | HTML / CSS / JavaScript。フロントエンドのビルド工程なし |
| 推論 | Irodori-TTS-v4.1-Small、CUDA。初回生成時にランタイムをロード |

ローカル用。外部公開は想定しない。Host制限・他Originからの変更要求拒否がある。TTS本体やその環境を無断で変更しない。

共通上部にプロジェクト選択、新規、台本読込、保存、保存オプション、開くを置く。

| タブ | 内容 |

タブ切替だけでは入力・行選択を破棄しない。行一覧は内部スクロール。タブは矢印・Home・Endキーでも切替可能。

## 4. 台本取り込み・行編集

### 台本

- txt: UTF-8（BOMあり/なし）、CP932、Shift_JIS。1行1セリフ。空行を除き、前後空白を除去。
- CSV: 同じ文字コードに対応。カンマ・改行を含むセルはCSV規則に従って引用する。
- 見出しあり: `セリフ` / `text`、`マスター` / `master`、`末尾無音ms` / `pause_ms`。列順は自由。セリフ列必須。重複・未知の見出しは拒否。
- 見出しなし: セリフ、マスター、末尾無音msの固定順（1〜3列）。先頭行もデータとして扱う。見出し判定は既知の列名との一致による。
- CSVの空セリフ行は読み飛ばす。未登録マスター、不正な無音値、列超過などは行番号付きエラー。
- CSVのマスター指定は登録名。英字の大小を区別しない。空欄または「共通マスター」は共通音声。
- 読込は新しい作業プロジェクトを作成する。既存行への追記ではない。

### 行

字幕、読み上げ、話速、指定Seed、マスター、末尾無音を編集できる。「あ」ボタンで実際のTTS送信文を確認する。
行追加はその場で入力してボタンまたはEnter。行削除・移動で行番号を1から振り直す。
クリック、Ctrlクリック、Shiftクリックで選択。全行選択あり。
左端「⋮」のドラッグで移動し、行の上半分/下半分で挿入位置を決める。連続した選択行は元の順序を維持してまとめて移動する。離れた複数行の一括移動は拒否。
移動では字幕・読み・音声・Seed・マスター・無音・履歴情報を保持する。WAVファイル名を行番号に合わせて変更しない。

### 初期値・範囲

| 項目 | 仕様 |
|---|---|
| 話速 `duration_scale` | 初期設定0.85、範囲0.25〜4、入力ステップ0.05。小さいほど短く速い |
| Seed | 空欄はrandom、固定値は0〜4294967295。実使用値は別に保存 |
| 末尾無音 | 0〜60000msの整数。上下操作は50ms刻み、手入力は整数単位 |
| txt取り込みの無音 | 200ms |
| CSVの無音省略・空欄 | 0ms |
| 新しく追加する行・旧データの無音未設定 | 0ms |

一括適用は選択した行だけが対象。全行変更したければ全行選択する。

## 5. 生成と再生成条件

未生成を生成、選択行を生成、全行を再生成を備える。「未生成」モードは生成済み以外（変更あり・エラーを含む）が対象。
ジョブはプロセス内で1つ。行順に処理し、1行の失敗があっても後続を試す。
Seed方式は行設定、新しいランダム、前回と同じ。前回値がない場合はランダム。

生成を中断すると停止要求を記録し、現在の行の処理・保存が終わったら次の行へ進まず終了する。即時キャンセルではない。完了分を保持し、未生成モードで残りを再開できる。
生成中は行編集・移動・プロジェクト操作等を制限するが、連続再生は操作可能。

| 変更 | 音声の再生成 |
|---|---|
| 読み上げ文、話速、指定Seed、行マスター | 必要 |
| 辞書・数字補正・共通音声 | 実際の送信文/参照音声が変わる生成済み行は必要 |
| 字幕のみ | 不要 |
| 行の順番 | 不要 |
| 末尾無音 | 不要 |
| 字幕折り返し | 不要 |
| Post Processing | 不要 |

状態は `pending / generating / generated / stale / error`。旧WAVは変更あり状態でも保持。前回の生成中断・ファイル欠落は読込時にエラーへ戻す。

## 6. テキスト・音声の処理順

```text
読み上げ文 → 読み辞書 → 数字正規化 → TTS → 元WAV
元WAV → Post Processing（有効時）→ 末尾無音追加 → 試聴 / 出力WAV
字幕文 → 自動折り返し（有効時）→ 出力txt
```

辞書は長い表記を優先した一度の置換で、置換結果を連鎖置換しない。数字正規化は `app/preprocessing.py` が定義する範囲で実施する。入力欄・字幕は書き換えない。

### 字幕折り返し

出力txtの書き出し直前だけ適用。30文字以内はそのまま。超えた場合は中央±5文字で自然な区切りを探し、中央に近い候補を優先。同距離なら句読点を優先する。候補がなければ文字種境界、最後に中央に近い安全な位置を選ぶ。
自動改行は最大1つ。手動改行を保持。数字・英数字のまとまりやカタカナ語の途中を避け、安全に分割できない単一トークンは1行のまま。形態素解析ではない。

### 末尾無音

元WAV末尾への追加時間。既存の無音を検出・除去したり、合計無音を指定値に揃える処理ではない。元WAVは変更せずキャッシュを作る。変更を繰り返しても無音は累積しない。

### Post Processing

全プロジェクト共通設定。全体の初期値はOFF。非破壊でキャッシュ生成する。

| 設定 | 初期値 / 範囲 |
|---|---|
| EQ | ON、プリセット「耳当たりを柔らかく」 |
| 中心周波数 | 3500Hz / 20〜20000Hz |
| ゲイン | −1.5dB / −12〜+12dB |
| Q | 1 / 0.1〜10 |
| Peak制御 | ON、−1dBFS / −24〜0dBFS |

プリセットは「なし」（EQゲイン0）・「耳当たりを柔らかく」・「カスタム」。EQの後にPeak制御。Peak制御はサンプルピークを超えた音声全体を減衰する方式で、コンプレッサーやTrue Peakリミッターではない。弱い音を持ち上げない。
保存した設定を試聴と出力に適用する。補正前/後の比較試聴あり。後の試聴は全体ON/OFFにかかわらず個別のEQ/Peak設定を使う。
保存時は連続再生・比較試聴を停止し、音声URLへ設定識別値を含めて古い音声を再利用しない。プリセット固定値は定期更新で編集可能に戻さない。旧保存値がプリセット名と不一致なら実値を保ってカスタム表示する。

## 7. 連続再生

選択なしなら先頭、選択ありなら最初の選択行から末尾まで。選択行だけを再生する機能ではない。
▶で開始/再開、■で位置を保持して一時停止。行送りで現在行を選択・スクロールする。
生成中の対象行は完成まで待機。生成対象外で再生できない行はスキップ。中断後の未完成行もスキップする。
手動選択変更、プロジェクト切替、生成開始、行削除、無音変更、個別音声再生、補正設定保存などでは再生位置をリセットする。再読込後の位置復元はない。

## 8. YMM4出力

- 全行または選択行のみ。対象に未生成・変更あり・エラーがあれば拒否。
- 指定フォルダ直下に出す。中間フォルダを作らない。
- GUIで出力先が空ならWindowsフォルダ選択。キャンセルなら出力しない。
- ファイル名例: `001_20260913_123456_78_seed12345.wav` と同名の `.txt`。
- 行番号、ローカル出力日時、小数秒2桁（10ms）、実使用Seed。旧データでSeed不明ならunknown。
- 1回の出力内は共通日時。衝突時は10msずつ進めて未使用名を選ぶ。
- 行順に出力。字幕txt（UTF-8 BOM）を完成させ、コピー済み一時WAVを正式名にして公開する。次の行まで1秒待つ。
- YMM4の取り込み完了を直接確認する仕組みではない。失敗時は出力済みの一部が残ることがある。
- 既存出力を上書き・自動削除しない。設定変更・移動は出力済みファイルに反映されないため再出力が必要。
- TTS本体とエディター作業データの保護対象フォルダへの出力を拒否する。

## 9. 保存・マスター管理

作業内容の自動保存は内部 `project.json`。明示的な保存は指定した `.irodori`。この2つを混同しない。編集の自動保存だけでは外部の保存ファイルは更新しない。
`.irodori` はZIPで、プロジェクトJSON、元生成WAV、使用するマスター音声を含む。辞書、Post Processing等の全体設定は同梱していない。異なる全体設定で開けば送信文や出力音が変わり得る。
開くと新しい内部作業プロジェクトを作る。同梱マスターは内容のSHA-256で既存登録と照合し、同じID、同名、その他一致音声の順で再利用する。ID/名前が同じでも音声内容が違えば別登録。同じファイルを開き直すたびに登録を増やさない。

マスターは登録名・元ファイル名・保存先を区別する。コピー先の内部ファイル名はUUIDの場合がある。古い登録には元名がない場合がある。登録名変更、共通設定への適用、使用プロジェクト/行数確認、未使用登録の削除に対応する。
削除は登録解除でWAV本体を残す。共通または行で使用中の登録を拒否。既にできた重複登録の自動整理機能はない。

## 10. 選択ダイアログ

台本、共通マスターWAV、登録マスターWAV、プロジェクトを開く、名前を付けて保存、出力先はそれぞれ前回のフォルダを記憶する。`dialog_locations.json`へ永続保存。キャンセルで更新しない。記憶先が存在しなければ通常の初期場所へ戻る。
現在の記憶キーはダイアログ種別＋タイトル。タイトル変更時には記憶の互換性を考慮する。

## 12. API案内

API定義と入力モデルの正本は `app/main.py`。ローカル `/docs` でスキーマを確認できる。

| 系統 | 主なパス |
|---|---|
| 状態・設定 | `/api/state`, `/api/settings`, `/api/settings/post_processing` |
| プロジェクト | `/api/projects`, `/api/projects/new`, `/api/projects/open-file`, `/api/projects/{pid}`, `/api/projects/{pid}/save` |
| 行 | `/api/projects/{pid}/rows`, `/rows/{rid}`, `/move-rows`（後二つも同じプロジェクト接頭辞） |
| 生成 | `/api/projects/{pid}/generate`, `/stop-generation`（同接頭辞） |
| 音声・出力 | `/api/projects/{pid}/audio/{rid}`, `/api/projects/{pid}/export` |
| マスター | `/api/masters`, `/api/masters/upload`, `/api/masters/{mid}`, `/api/reference` |
| 辞書 | `/api/dictionary` |
| ダイアログ | `/api/dialog/script`, `/voice`, `/master`, `/output`（いずれもdialog接頭辞） |

音声取得のvariantは `auto / raw / processed`。通常試聴・出力はauto、比較用はraw/processed。rawの指定でも末尾無音は適用される。

## 13. 制約と今後の検討

- デスクトップアプリ化は検討段階。現行仕様に混ぜて実装済みと扱わない。
- Post Processingは共通設定で、プロジェクト固有保存は未対応。
- 加工キャッシュの容量制限・自動掃除、重複マスター整理、Undo/Redoは未実装。
- 生成・出力・加工には共有ロックがある。長い処理中の応答性とロック範囲に注意する。
- APIテストだけではブラウザのキャッシュ・音声状態やYMM4の取り込みを保証できない。

開発時のルール・確認手順は [DEVELOPMENT.md](DEVELOPMENT.md) を参照。
