# Irodori-TTS-Editor

Windowsローカル専用のYouTubeナレーション制作エディタ。1行＝1セリフの台本を一括生成し、気になる行だけ読み・話速・Seedを直して再生成できます。

## 初回セットアップ・起動

固定版と最新版を分離して使う場合は [環境切替の手順](docs/ENVIRONMENTS.md) を参照。作成後は `start-stable.bat`（固定版）または `start-latest.bat`（試用版）で起動する。

このPCでは必要なライブラリが既存の `E:\Irodori-TTS\.venv` に揃っていることを確認済みです。追加インストールは不要です。

エクスプローラーから **`start.bat` をダブルクリック**して起動できます。PowerShellの実行ポリシーには依存しません。起動後、ブラウザで <http://127.0.0.1:8765> を開いてください。起動エラーが出た場合はウィンドウを残してメッセージを表示します。

PowerShellから起動する場合：

```powershell
cd E:\Irodori-TTS-Editor
.\start.ps1
```

PowerShellの実行ポリシーでスクリプトが実行できない場合：

```powershell
& E:\Irodori-TTS\.venv\Scripts\python.exe -B .\run.py
```

uvがPATHにある環境なら `uv run python run.py` でも起動できます。現在の実行環境ではuvがPATHにないため、上記の起動方法を確認しています。

ブラウザで <http://127.0.0.1:8765> を開きます。終了は起動したターミナルで `Ctrl+C`。同時に起動するサーバーは1つにしてください。`--reload` や複数workersは使わないでください。

## Irodori-TTSとの依存関係

- エンジン本体：`E:\Irodori-TTS`（読み取り専用。コード・pyproject・仮想環境を変更しません）
- 実行Python：そのエンジンの `.venv\Scripts\python.exe`
- FastAPI、uvicorn、python-multipartと、Irodoriの既存CUDA依存を利用します。
- エディタ自体のuv環境にPyTorchを再インストールしません。`run.py` が既存エンジンPythonを呼び出します。
- 別の設置場所では起動前に `$env:IRODORI_HOME = 'D:\Irodori-TTS'` を設定します。
- モデルは最初の生成時に1回ロードし、単一のバックグラウンド処理で再利用します。
- 初回モデル取得などにはHugging Faceへの接続が必要になる場合があります。音声生成はローカルです。
- APIはインストール済み `irodori_tts/inference_runtime.py` の `InferenceRuntime / RuntimeKey / SamplingRequest` を確認して実装しました。

生成設定は `Aratako/Irodori-TTS-v4.1-Small`、40 steps、Text CFG 3.0、Speaker CFG 5.0、model/codecともCUDA・fp32。その他は現行 `SamplingRequest` のデフォルトです。

## 基本操作

### 連続再生・選択出力・新規プロジェクト

- 「全行を連続再生」「選択行を連続再生」で生成済み音声を行順に再生します。未生成・変更あり・エラーの行はスキップします。連続再生用プレイヤーで一時停止・再開・シーク、「停止」で終了できます。個別音声の再生、プロジェクト切替、音声生成開始時は連続再生を停止します。
- 行を選択して「選択行だけ出力」を押すと、選択した音声と字幕のみを指定フォルダ直下へ書き出します。元の行番号を維持し、その後ろに出力日時（小数秒2桁）と使用Seedを付けます。WAVとtxtは同じ名前です。選択外の未生成行は出力を妨げません。選択した行は生成済みである必要があります。字幕折り返し設定も適用します。既にフォルダにある選択外のファイルは削除しません。
- 「新規プロジェクト」で空のプロジェクトを作成できます。「追加するセリフ」欄に入力し「＋ 行追加」またはEnterで末尾に追加します。日本語変換の確定Enterでは追加しません。字幕と読み上げは入力文で初期化され、追加後に別々に編集できます。話速は現在のデフォルト設定を使います。プロジェクト未選択なら行追加時に新規作成します。
- 台本txtの読み込みでも新規プロジェクトを作成します。同じ台本を再読込した場合も別プロジェクトを作り、以前のプロジェクトは一覧に残ります。行追加も自動保存されます。`.irodori` ファイルへ反映する場合は「プロジェクトを保存」を押してください。

1. 「音声・デフォルト設定」でReference Audioを指定します。絶対パスを入力して保存、またはWAVを選択します。ファイル選択の場合は `voices/` にコピーします。設定は次回起動時にも復元されます。
2. 「台本txtを読み込む」で台本を選択します。UTF-8（BOMあり・なし）、CP932、Shift_JISに対応。空行は除外し、前後の空白を取り除きます。読み込みごとに独立したプロジェクトを作ります。
3. 字幕と読み上げは別々に編集できます。欄からフォーカスを外すと自動保存します。字幕は改行も可能です。
4. 行の「生成」、行を選択して「選択行を生成」、または「すべて生成」（生成済み以外の行をまとめて生成）を押します。全行を作り直すときは全行を選択して「選択行を生成」を押します。
5. 生成後、行のプレイヤーですぐ試聴できます。
6. 読みや話速を変更した行は「変更あり」になります。再生成してから出力してください。字幕だけの変更では音声を作り直しません。

台本例：

```text
こんにちは、ichigoです。
今回は藍属性の編成について解説します。

まずは夏プリマから見ていきましょう。
```

この例は3セリフです。`tests/sample.txt` に短い動作確認用台本もあります。

## 数字の読みを自動補正

「音声・デフォルト設定」の「数字の読みを自動補正」でON/OFFを選び、「設定を保存」を押します。初期値はONです。設定は全プロジェクト共通です。

読み上げ欄の内容にユーザー辞書を適用した後、Editor側の `app/preprocessing.py` で数字を正規化します。入力欄・字幕・出力txtは変更せず、読み上げ欄の下に実際のTTS送信文を表示します。生成履歴の `effective_text` にも送信文が残ります。設定や辞書の変更で送信文が変わった生成済み行は「変更あり」になり、以前のWAVを残したまま再生成対象になります。

例：

- `攻撃力が3136増加する` → `攻撃力がさんぜんひゃくさんじゅうろく増加する`
- `3ターンの間、攻撃力が30%増加する` → `さんたーんの間、攻撃力がさんじゅっぱーせんと増加する`
- `Lv240でスキルが解放される` → `れべるにひゃくよんじゅうでスキルが解放される`

対応範囲：半角整数0〜999,999,999、正しい3桁カンマ区切り、小数（小数部分は1桁ずつ）、%・％、Lv/LV/lv、ターン・体・回・人・個、第N章。一般的な百・千・助数詞の音便に対応します。追加ライブラリは不要です。

製品名などの英数字混在文字列、URL、代表的な拡張子のファイル名、Windows/相対/絶対パスは保護します。先頭ゼロ付き整数、10桁以上、壊れたカンマ区切りなどはそのまま残します。全角数字、日付・時刻・電話番号の専用読み、全助数詞、すべての製品名・ファイル名の認識は未対応です。特殊な読みは辞書、または既存の読み上げ欄へ直接かなを入力して調整してください。

新しいコードを反映するには起動ターミナルを終了し、`start.bat` または `start.ps1` で再起動してからブラウザを再読み込みしてください。

## 話速・Seedの指定

`duration_scale` は1.00が標準、0.95は少し速く、1.05は少し遅くなります。0.25〜4.0の範囲に制限しています。上部のデフォルト値は新規読み込みに適用されます。「選択行に話速を適用」で既存行を一括変更できます。

Seed欄の空欄はrandom、数値は固定Seed（0〜4294967295）。「前回」に実際の使用Seedを表示します。上部のSeed方式で行設定・新しいランダム・前回と同じSeedを切り替えます。前回Seedがない行はランダムです。同じSeedでもエンジン・GPU・設定の変更をまたいだ完全一致は保証されません。

## 読み辞書

「読み辞書」で表記と読みを追加・編集・削除し、チェックで有効／無効を切り替え、「辞書を保存」を押します。

例：`LR5 → エルアールご`、`藍属性 → あいぞくせい`。

字幕は変更しません。読み上げ欄の下に、辞書適用後の送信文を表示します。長い表記を優先し、置換結果に再度辞書を適用しません。辞書は全プロジェクト共通で `dictionaries/reading.json` に保存します。辞書変更で送信文が変わった生成済み行は「変更あり」になります。

## YMM4用出力

全行生成後、「全行を出力」を押します。出力先が空欄の場合はWindowsのフォルダ選択ダイアログが開きます。キャンセルした場合は出力しません。指定フォルダ直下にWAVとtxtを出力します。ファイル名は `行番号_YYYYMMDD_HHMMSS_小数秒2桁_seed使用Seed` です。再出力でも既存ファイルは上書きしません。中間フォルダは作りません。行数が減った場合の余分な番号のファイルは自動削除しないため、必要に応じて別の出力先を指定してください。Irodori本体配下への出力は禁止しています。

```text
001_20260908_123456_78_seed12345.wav
001_20260908_123456_78_seed12345.txt
002_20260908_123456_78_seed67890.wav
002_20260908_123456_78_seed67890.txt
```

全体が1000行以上なら全ファイルを同じ桁数に揃えます。txtはUTF-8 BOMです。字幕欄の内容に字幕自動折り返しを適用して出力します（設定OFFならそのまま）。手動改行は維持します。画面に表示された出力フォルダをYMM4で指定してください。

出力欄の下に書き出し可能な状態かどうかと、最後に書き出したフォルダを常時表示します。出力先はプロジェクトにも保存されます。音声を生成しただけではYMM4用フォルダには書き出されません。

外部フォルダへの書き込みでアクセス拒否になる場合、Codexの制限付き環境でサーバーを起動していないか確認してください。通常のPowerShellから `start.ps1` で起動すれば、ログインユーザーが書き込めるフォルダへ出力できます。

未生成・変更あり・エラーの行が残っている場合は出力しません。古い音声と新しい読み上げの混在を防ぐためです。完成した出力フォルダは独立したコピーです。再編集した場合は再出力してください。

## 保存・途中再開・ログ

```text
projects/<id>/project.json       台本・字幕・読み・話速・Seed・状態・エラー
projects/<id>/audio/001.wav      生成音声
projects/<id>/generation.jsonl   各生成の履歴（使用Seed・実送信文を含む）
```

JSONは一時ファイルからの置換で保存し、音声も生成成功後に入れ替えます。再生成が失敗しても前回のWAVは保持します（状態はエラー）。1行のエラーでは次の行へ進みます。再起動後はプロジェクト一覧から開き、「すべて生成」でエラー・変更ありを含め続きから再開できます。

生成中に終了した行や、音声ファイルが欠けた生成済み行は、読み込み時にエラーへ戻します。画面の行エラー、`generation.jsonl`、起動ターミナルの出力を確認してください。モデル読み込み失敗やCUDAメモリ不足の場合は、他のGPUアプリを閉じ、原因を解消してから再生成してください。

## プロジェクトファイルの保存・読み込み

出力先設定は画面上部にあります。「参照…」でWindows標準のフォルダ選択ダイアログを開きます。指定したフォルダ直下にWAVと字幕を書き出します。

作業画面は「エディター」「読み辞書」「設定」のタブで切り替えます。音声・デフォルト設定は「設定」に、保存名と「名前を付けて保存…」は上部の「保存オプション」にまとめています。タブを切り替えても入力内容は保持されます。出力先が空欄なら全行・選択行どちらの出力ボタンでもフォルダ選択を開きます。

「プロジェクトを保存」は初回にWindows標準の保存ダイアログを開き、場所とファイル名を指定します。保存済みなら同じファイルを更新します。「名前を付けて保存…」は毎回保存ダイアログを開きます。キャンセルした場合は保存先やプロジェクト名を変更しません。

`.irodori` は台本・字幕・読み・話速・Seed・出力先・生成済みWAVを含む単一ファイルです。「プロジェクトを開く…」で選択すると作業用プロジェクトとして読み込みます。保存先を変える場合は「名前を付けて保存…」を使用してください。

行編集の自動保存は従来どおりアプリのprojectsフォルダ内に行います。指定した `.irodori` ファイルへ最新の編集・音声を反映するには「プロジェクトを保存」を押してください。Reference Audio設定と読み辞書はアプリ全体で共通です。読み辞書はプロジェクトファイルに含めません。使用中のマスター音声は下記ステップ2の方式で同梱します。

Windowsダイアログはサーバーを起動したPCに表示されます。通常のWindowsユーザーのPowerShellから起動してください。

## 字幕を自動折り返し

「音声・デフォルト設定」の「字幕を自動折り返し」を選び、「設定を保存」でON/OFFを保存します。初期値ON、全プロジェクト共通です。変更はYMM4用出力時に適用され、音声の再生成は不要です。

`app/subtitle_formatter.py` の `format_subtitle()` をtxt書き出し直前だけに使用します。保存済みの `original_text`、編集可能な `subtitle_text`、`speech_text` を変更しません。読み上げ用の辞書・数字正規化とは独立しています。字幕欄は元の編集内容を表示し、折り返し結果は出力txtで確認します。

30文字以内は改行せず、超えた場合は文章全体の中央付近（前後5文字）で、句読点や助詞の後など自然な区切りを探します。中央に近い候補を優先し、距離が同じなら句読点を優先します。候補がなければ中央付近の文字種の境界、最後に中央に最も近い安全な位置で折り返します。完全な形態素解析ではないため、すべての単語境界を保証するものではありません。

数字・英数字と記号のまとまり（3136、30%、3.5%、Lv240、Irodori-TTS、A.I.VOICE2など）やカタカナ語の途中は避けます。長い単一の英数字トークンなど安全な分割位置がない場合は1行を維持します。改行位置の前後で文字や空白を削りません。

自動挿入は最大1個で、60文字を超えても残り全文を2行目に置きます。セリフ・音声・YMM4アイテムを分割しません。手動改行がある字幕には処理を加えません。手動で3行以上になっている字幕は、既存編集を壊さないため例外としてそのまま出力します。

確認例：

```text
このキャラは高い耐久力を持っているため、
長期戦でも安定して活躍することができます
```

機能反映には `start.bat` / `start.ps1` でサーバーを再起動し、ブラウザを再読み込みしてください。その後YMM4用出力を実行し、出力先のtxtを確認してください。

出力日時はPCのローカル時刻で、1回の出力内では共通です。小数秒2桁は10ミリ秒単位です。名前が重なった場合は10ミリ秒ずつ繰り上げて未使用名を選びます。Seedは音声生成時の実使用値（記録がない旧データのみunknown）。WAV・txtとも既存ファイルを上書きしないモードで作成します。行番号順、同じ行では出力日時順に並びます。


## 行操作の更新（ステップ1）

- 行の余白または行番号をクリックすると単一選択。選択済みの行を再クリックすると、その行の選択を解除します。Ctrl＋クリックで追加・解除、Shift＋クリックで直前の選択起点から範囲選択。Ctrl＋Shiftでは範囲を追加します。入力欄・ボタン・音声プレイヤーの操作では選択を変更しません。行へキーボードフォーカスを移し、Space / Enterでも選択できます。
- 各行の「🗑」で行を削除し、自動保存します。以降の行番号は詰め直します。生成中は削除できません。削除の取り消しは未対応です。既存の保存済み `.irodori` は「プロジェクトを保存」するまで変更しません。
- 専用の「読み確認」列の「あ」で辞書・数字補正後の実際のTTS送信文をモーダル表示します。閉じるボタン・Esc・背景クリックで閉じます。全文のかな変換ではありません。
- 削除した行の作業用WAVは自動消去しません。残った行の音声を保護するため、生成時にファイル名の衝突を避けます。プロジェクト保存・出力には残っている行だけが含まれます。

## 次の実装ステップ

2. 名前付きマスター音声の登録、行ごとのプルダウン指定、一括生成対応。
   - ここでのマスターはTTSチェックポイントではなく参照音声。通常用と `master_flat` などを登録する。
   - 行に個別指定がなければ共通マスターを使用。旧プロジェクトはこの動作で互換性を保つ。
   - 生成開始時に対象行の参照音声を検証・確定し、同じロード済みTTSモデルへ行別に渡す。
   - マスター変更時は影響する行だけを「変更あり」にする。参照音声と登録情報のプロジェクト保存方式も合わせて実装する。
3. マスター名付きCSVインポート。
   - 通常txtは従来どおり1行1セリフ。CSVを明示してセリフとマスター登録名を指定する。
   - セリフ中のカンマはCSVの引用符で扱う。未登録のマスター名はインポート時に行番号付きで通知し、黙って共通マスターへ置換しない。
   - 列名・空欄時の扱いを画面とサンプルへ明記する。

## 行別マスター（ステップ2）

1. 設定タブの「マスター音声の登録」で `master_normal` / `master_flat` などの名前を入力し、WAVを選択するか絶対パスを指定して登録します。両方未指定なら保存済みの共通Reference Audioをコピーします。名前の重複は大文字・小文字を区別せず拒否します。
2. エディター右端の「マスター」列で行ごとに選択します。変更は自動保存され、生成済みの行は「変更あり」になります。
3. 「共通マスター」の行と個別指定の行を混ぜたまま、全行・選択行・未生成の一括生成ができます。TTSチェックポイントは共通で、行ごとに参照音声を切り替えます。

既存プロジェクトと追加行は「共通マスター」です。登録一覧の「共通マスターに設定」でもデフォルトを変更できます。共通マスターの変更は個別指定の行には影響しません。生成開始前に対象行すべての参照音声を確認し、不明な登録やファイル欠落があれば該当行を表示して開始を止めます。生成中の登録・切替はできません。

登録音声はコピーして保持するため、登録元のWAVを移動しても使用できます。登録名の変更・削除・音声差し替えUIはこの段階では未対応です。

`.irodori` には使用しているマスター音声も同梱します。読み込むと独立したマスターとして復元し、同名が登録済みなら `(2)` などを付けます。保存時に「共通マスター」だった行も、読み込んだプロジェクトでは保存時の音声を個別指定して再現します。必要ならプルダウンで現在の共通マスターへ戻せます。旧形式のファイルは従来どおり共通マスターを使用します。

ステップ2検証：Python 21件（混在生成、未登録・欠落、共通音声変更の影響範囲、マスター同梱と復元後の生成を含む）、JavaScript構文チェック、再生キューテストが通過。生成テストは代替エンジンで行い、GPU実生成と実ブラウザ操作は未確認です。


## CSV台本インポート（ステップ3）

「台本txt / CSVを読み込む」で `.csv` を選択します。先頭の空行を除いた1行目に列名を入れてください。列名は `セリフ,マスター` または `text,master`。順序は入れ替え可能で、マスター列は省略できます。未対応の列名や重複列はエラーになります。

```csv
セリフ,マスター
通常の声で読みます。, 
感情を抑えて読みます。,master_flat
再び通常の声です。
"カンマ,を含むセリフです。",master_flat
```

マスター名は設定タブで登録した名前に合わせます。WAVファイル名やTTSモデル名ではありません。前後の空白を除き、英字の大文字・小文字は区別しません。`master_flat` は事前に登録してください。`共通マスター` という名前の指定・空欄・行末のマスター値省略・マスター列自体の省略は、すべて共通マスターになります。`共通マスター` は登録名より優先して共通設定として解釈します。`master` という文字を指定した場合は、その名前の登録を探します。

マスター列なしの例：

```csv
セリフ
通常の声で読みます。
この行も共通マスターです。
```

UTF-8（BOMあり・なし）、CP932、Shift_JIS対応。セリフ中のカンマや改行はダブルクォートで囲み、引用符自体は二重にします。完全な空行はスキップします。未登録名や不正な行がある場合はファイル全体の取り込みを止め、行番号付きで通知します。通常の `.txt` は従来どおり1行1セリフ・共通マスターで、カンマを区切りとして扱いません。

検証：Python 22件とJavaScript構文チェック通過。CSVの文字コード、列省略、空欄、引用符・改行、未登録名、不正CSV、取り込み後の混在生成を確認済み。実ブラウザ操作とGPU実生成は未確認です。


## 行ごとの末尾無音（ミリ秒）

「末尾無音(ms)」列で0〜60000の整数を指定します。200ms = 0.2秒、1000ms = 1秒。台本(.txt)取り込み時は200msが既定値です。旧プロジェクト・追加行・CSVの無音列省略/空欄は0msです。無音だけの変更はTTS再生成不要で、自動保存されます。

個別試聴・連続再生・全行／選択行WAV出力は同じ無音付き音声を使用します。元の生成WAVを保持し、その末尾に指定時間を追加した音声をキャッシュします。値を減らしたり0へ戻しても、無音が累積することはありません。`.irodori` には元音声と無音設定を保存し、再読込時にも同じ長さで再現します。

**指定値は元WAVの末尾へ追加する長さです。** 元々の音声にある余白は削りません。発声終了を検出して末尾全体の無音を指定値へ揃える機能ではありません。時間はサンプル単位へ丸めます。

CSVには任意列 `末尾無音ms`（英語名 `pause_ms`）を追加します。

```csv
セリフ,マスター,末尾無音ms
まずは概要を説明します。,共通マスター,200
ここが重要なポイントです。,master_flat,600
次の話題に移ります。,共通マスター,1000
```

列順は自由です。無音列の空欄・列そのものの省略は0ms。負数・小数・単位付き文字列・60000超は行番号付きエラーになります。マスター列を省略して `セリフ,末尾無音ms` だけでも使えます。既存の1列・2列CSVも継続して使えます。

文脈に応じた時間の決定は外部で行い、この形式へ変換して取り込んでください。エディター内のAI変換は実装していません。YMM4側でも余白を追加すると、その分はさらに加算されるため、WAV内の無音だけで調整する場合はYMM4側の追加余白を0にしてください。

検証：Python 23件、JavaScript構文チェック、再生キューテスト通過。実PCM WAVで200msのサンプル数、音声部分の保持、試聴と出力の一致、無音の増減・0への復帰、保存・再読込を確認。実ブラウザ・GPU・YMM4操作は未確認です。


## 連続再生トグル

連続再生操作は幅100pxの「▶／■」ボタンに統合しました。

- 選択なし：先頭から末尾まで。選択あり：一番上の選択行から末尾まで。未生成・変更あり・エラー行はスキップします。
- 再生中は「■」。押すと行内の秒位置を保持して停止し、「▶」で同じ位置から再開します。読み込み済みの音声を保持するため、末尾無音の途中で停止した場合もその位置から続きます。
- 再生が次の行へ進むたび、その行だけを選択状態にし、画面内にスクロールします。
- 手動で行選択を変更すると停止位置をリセットし、次の▶は新しい選択行から開始します。複数選択の場合も最初の選択行以降をすべて再生します。
- プロジェクト切替、生成開始、行削除、末尾無音変更、個別音声再生でも連続再生位置をリセットします。停止位置の保持は現在の画面内のみで、ブラウザ再読み込み後の復元は対象外です。

JavaScript構文チェックと再生キューテスト（停止位置保持、再開、次行選択通知、完了・リセット）を確認。実ブラウザ操作は未確認です。


## コンパクトな操作画面

出力先・対象（全行／選択行のみ）・出力ボタン・生成ボタンを1行に統合しました。出力対象はプルダウンで明示的に選択します。Seed方式は設定タブの「生成設定」にあります。

保存先と前回の出力先、CSV・行選択の長い説明は常時表示しません。出力エラーは引き続き表示します。エディターはウィンドウの高さに合わせ、行一覧の内部でスクロールします。設定・辞書も各タブ内でスクロールします。幅が狭い場合、出力・生成バーは横スクロールで操作できます。

### ドラッグで行を移動

行の左端「⋮」をドラッグし、移動先の行の上半分または下半分にドロップします。挿入位置を線で表示します。複数行は先頭行をクリックし、末尾行をShiftクリックして連続選択した後、選択行の「⋮」をドラッグします。選択内の順序を保持してまとめて移動し、行番号を振り直します。音声・字幕・読み・Seed・マスター・末尾無音は保持し、自動保存します。生成中は移動できません。離れた行の一括移動は連続選択にし直してください。出力済みファイルの順番は変わらないため、YMM4用には再出力してください。

YMM4用出力は行順に1組ずつ行い、次の行の出力まで1秒待ちます（全行・選択行共通）。字幕txtを先に完成させ、WAVは一時ファイルへのコピー完了後に正式名で配置します。YMM4の取り込み完了を確認する方式ではありません。

「一括」タブでは、エディターで選択した行に話速・末尾無音をまとめて適用できます。全行変更はエディターで全行選択してから適用します。末尾無音の上下操作は各行・一括とも50ms刻みです。手入力では0〜60000msの整数を指定できます。

生成中でも連続再生の開始・一時停止ができます。生成対象の未完成行では待機し、完成後に続けます。「中断」（生成・出力の両方に使えます）は現在の行の処理と保存（出力中は現在のファイル）が完了してから次に進まず停止します。「すべて生成」で残りを再開できます。中断後、再生できない未完成行はスキップします。

マスター管理では登録名の変更、使用プロジェクト・行数の確認、未使用登録の削除ができます。削除は登録解除のみでWAV本体を残します。新規アップロードは元ファイル名を記録し、画面には登録名・元ファイル名・内部保存先を区別して表示します。以前の登録で元ファイル名が残っていない場合は「記録なし」と表示します。

CSVは見出しなしでも読み込めます。その場合の列順は「セリフ,マスター,末尾無音ms」で、マスター以降の列は省略できます。1行目のセリフも取り込みます。見出し付きCSVも従来どおり使用できます。

台本・共通マスターWAV・登録マスターWAV・プロジェクトを開く・名前を付けて保存・出力フォルダの各選択ダイアログは、前回選択した場所をボタンごとに記憶します。`dialog_locations.json` に保存するため再起動後も有効です。キャンセルでは更新せず、記憶先がなくなった場合は通常の初期場所に戻ります。
